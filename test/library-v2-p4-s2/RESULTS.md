## Final correction (Architect review of c48d7de) - results
1. **Unicode preservation**: stored/display values keep the exact Unicode sequence (NFC, NFD, mixed, full-width) after the approved whitespace trim; canonical equivalence is used only for comparisons (P3 `canonicalizeNodeCode`: duplicate codes, subject references). Plan, payloads and verification block carry the preserved sequence. Length bounds are measured on the stored sequence (P3).
2. **styles.xml**: when present it must be well-formed XML (new bounded checker `import-xml-wellformed.mjs`: balanced/matching tags, quoted unique attributes, legal entities and characters, one root, no DTD, depth/attribute bounds, UTF-8/UTF-16 with BOM) with a `styleSheet` root in the SpreadsheetML namespace and <= 4 MiB; an ABSENT part (with its relationship and content-type override removed) stays valid. 16 malformed fixtures x stored/deflated, oversized, invalid UTF-8, DTD, plus valid Excel-style variants (BOM, CRLF, comments, prefixed root, strict namespace).
3. **Diagnostics**: lessons that reference a subject whose own code cell was rejected (formula, control character) are grouped into ONE warning `LESSONS_OF_INVALID_SUBJECT` per subject; the root-cause error is the only error. Genuine orphans (and orphans of subjects with no recoverable code text) remain errors.
4. **Strictness**: unexpected worksheets and formulas remain errors; the policy is the pinned constant `TEMPLATE_STRICTNESS` in `import-template.mjs`.
5. **Browser capability**: `BROWSER_UNSUPPORTED` (stage 1) with `data.missing` capability ids (`worker`, `module-worker`, `decompression-stream`, `readable-stream`, `text-decoder`); `detectReaderCapabilities()` for a pre-check; `browserWorkerFactory` detects module-Worker support via the `options.type` getter probe; `validateImport(...).unsupportedBrowser/missingCapabilities`; fail closed - the page-side reader has no parsing path and the library is never called.
6. **Regression** (focused): P4-S2 76/76 pure + 9/9 emulator; directly affected guards 113/113 (P3-S2 model/write-contract/queries/source-guard, P3-S3/S4/S5 source guards, P3-S4 code-conflict, P3-S5 clone/delete units, P2-S2 source guard, P4-S1 Rules-bytes regression). Broad P2/P3 suites and the pre-existing group-pdf-v1 scope-lock failure were not touched or rerun.
